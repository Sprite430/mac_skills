# SQL 模板：已有 MVC 页面新增状态 / 列配置

## 适用场景

- 目标是已有 MVC 列表页。
- 页面状态、列显示、字段显隐由数据库配置控制。
- 只需要生成 SQL，不写页面代码逻辑。

## 先核对

生成前先确认这些值：

- `JSP_NAME`
- `VIEW_ID`
- `VIEW_ALIAS`
- `CONTROL_NAME`
- `STATUS_ID`
- `STATUS_CODE`
- `STATUS_NAME`
- `STATUS_ORDER`
- 新列的 `UI_ID`、`UI_NAME`、`DATAINDEX`、`UI_ORDER`、`UI_WIDTH`

## 1. 先查现有配置

```sql
SELECT STATUS_ID, STATUS_CODE, STATUS_NAME, JSP_NAME, STATUS_ORDER, IS_ENABLED
  FROM PB_SYS_STATUS
 WHERE JSP_NAME = '${JSP_NAME}';

SELECT STATUS_ID, VIEW_NAME, CONTROL_NAME, PAGESIZE, VIEW_ID, VIEW_ALIAS, IS_SUBTOTAL
  FROM PB_MODULE_STATUS_UI
 WHERE VIEW_ID = '${VIEW_ID}';

SELECT UI_ID, UI_NAME, DATAINDEX, UI_ORDER, IS_VISBLE, VIEW_ID
  FROM PB_MODULE_UI_DETAIL
 WHERE VIEW_ID = '${VIEW_ID}'
 ORDER BY UI_ORDER;
```

## 2. 新增状态 + 挂页面 + 配列

> 这是一套最完整的写法。  
> 如果只新增状态不改列，删掉第 4 段。  
> 如果只是改列显隐或顺序，只保留第 4 段。

```sql
-- 2.1 新增状态主记录
INSERT INTO PB_SYS_STATUS (
    STATUS_ID, STATUS_CODE, STATUS_NAME, CONDITION,
    REMARK1, JSP_NAME, STATUS_ORDER, IS_ENABLED
) VALUES (
    '${STATUS_ID}', '${STATUS_CODE}', '${STATUS_NAME}', '${CONDITION_SQL}',
    NULL, '${JSP_NAME}', ${STATUS_ORDER}, 1
);

-- 2.2 新增状态条件；一条条件一行，多个条件就多插几行
INSERT INTO PB_STATUS_CONDITION (
    STATUS_CID, OPERATION, ATTR_CODE, RELATION, VALUE,
    ALIAS, DATATYPE, STATUS_ID, TYPE, MENU_ID
) VALUES (
    '${STATUS_CID_1}', 'and', '${ATTR_CODE_1}', '${RELATION_1}', '${VALUE_1}',
    NULL, ${DATATYPE_1}, '${STATUS_ID}', 0, NULL
);

-- 2.3 把状态挂到页面
INSERT INTO PB_MODULE_STATUS_UI (
    STATUS_ID, VIEW_NAME, CONTROL_NAME, PAGESIZE, VIEW_ID, VIEW_ALIAS, IS_SUBTOTAL
) VALUES (
    '${STATUS_ID}', '${VIEW_NAME}', '${CONTROL_NAME}', ${PAGESIZE}, '${VIEW_ID}', '${VIEW_ALIAS}', ${IS_SUBTOTAL}
);

-- 2.4 配置该状态下显示的列；一列一行
INSERT INTO PB_MODULE_UI_DETAIL (
    UI_ID, UI_NAME, UI_XTYPE, UI_WIDTH, UI_ORDER, IS_VISBLE, DATAINDEX, LOCKED,
    FORMAT, VIEW_ID, ALIGN, IS_NULL, STORE_NAME, ACTION_NAME, REGEX, REGEXTEXT
) VALUES (
    '${UI_ID}', '${UI_NAME}', ${UI_XTYPE}, ${UI_WIDTH}, ${UI_ORDER}, ${IS_VISBLE}, '${DATAINDEX}', ${LOCKED},
    ${FORMAT}, '${VIEW_ID}', '${ALIGN}', ${IS_NULL}, ${STORE_NAME}, ${ACTION_NAME}, ${REGEX}, ${REGEXTEXT}
);
```

## 3. 只改列显隐或顺序

```sql
UPDATE PB_MODULE_UI_DETAIL
   SET IS_VISBLE = ${IS_VISBLE},
       UI_ORDER  = ${UI_ORDER},
       UI_WIDTH  = ${UI_WIDTH}
 WHERE VIEW_ID = '${VIEW_ID}'
   AND UI_ID   = '${UI_ID}';
```

## 4. 生成规则

- `STATUS_ID`、`STATUS_CID`、`UI_ID` 必须唯一。
- `PB_SYS_STATUS.CONDITION` 要和 `PB_STATUS_CONDITION` 的拆分条件保持一致。
- `PB_MODULE_STATUS_UI.VIEW_ID`、`VIEW_ALIAS`、`CONTROL_NAME` 必须和目标页面一致。
- `PB_MODULE_UI_DETAIL.DATAINDEX` 要和列表字段真实返回值一致。
- 如果目标库已有同名记录，先改成 `UPDATE`，不要重复 `INSERT`。
